Style guide

One page showing every color, font and control the app uses, with the rule for when each appears. The theme: ink on a drumhead. Teal always means “sound happens here” — the bar being played, the active version, the button that starts playback. Everything else stays quiet.

Type

Rosanna

Song titles and headings: Alegreya, the serif used above — it echoes the title page of an engraved score.

Body text and controls use Alegreya Sans, its matching sans-serif — this paragraph is set in it. Text lines stay under 65 characters so they read comfortably from a music stand’s distance.

Captions and statistics look like this: smaller, quiet ink.

Buttons

One teal button per screen — the main action. Everything secondary is a quiet outline. A button says what it does: “Transcribe”, not “Submit”.

Version and score tabs

Pills, not folder tabs. The chosen one is inked solid.

Score

The teal wash follows playback bar by bar. A red note is a low-confidence transcribed hit worth checking; a brass note carries your saved feedback. Click an empty spot in a bar to play from there; click a note to comment on it. The score is the central element of a project page — notation gets the room, and the player stays compact and within reach beside it.

Players

Players sit on white sound cards: a teal edge (this plays), a one-line caption saying what you are hearing, and the browser's own controls recolored to blend in.
